# MealShare

MealShare is a food donation and surplus meal sharing platform connecting food donors, listers, and community reservers.

## Project Structure

- **`Frontend/`**: React + Vite frontend application
- **`backend/`**: Node.js, Express, and MongoDB backend API

## Getting Started

### Frontend
```bash
cd Frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev # or npm start
```
